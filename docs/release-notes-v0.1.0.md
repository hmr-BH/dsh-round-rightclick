# dsh-round-rightclick v0.1.0

为 DeepSeek Harness Web 增加一个小巧的圆盘右键菜单，把会话常用操作放到鼠标附近。

## 主要功能

- 240 CSS 像素正圆菜单，提供六个 SVG 图标与轻量悬停光晕。
- 打开工作目录，复制路径或会话 ID，打断当前生成，导出会话日志。
- 在具体轮次的提问或回复上右键创建分支，保留截至该轮的完整对话并打开新会话。
- 页面顶部的成功提示带绿色圆形对勾，失败提示带红色圆形感叹号。
- 支持键盘导航、自动避让窗口边缘，以及处理中的重复点击保护。

## 安装

下载附件 `dsh-round-rightclick-0.1.0.tgz`，执行：

```sh
dsh plugin --profile web add ./dsh-round-rightclick-0.1.0.tgz
```

重启 `dsh web` 并刷新页面，在已有会话的对话区右键。卸载命令：

```sh
dsh plugin --profile web remove dsh-round-rightclick
```

Node.js 要求 `^22.19.0` 或 `>=24.0.0`。宿主分叉切分已针对本机 `0.1.2-rc.1` 的会话控制器做契约检查；其他宿主版本仍需确认接口兼容性。

## 验证范围

类型检查、构建、47 个自动化测试与本机宿主切分契约检查通过。macOS 和 Linux 仅验证文件管理器命令映射，尚未完成这两个平台的实机验收。
